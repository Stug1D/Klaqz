# Happy Birthday Mr Klaqz

## Audios einfügen

Lege deine Aufnahmen in den Ordner `audio`. Die bereits zugeordneten Nachrichten
sind:

- `Dustin.mp3` für Station 01
- `ErayAudio.mp3` für Station 02
- `MaxAudio.mp3` für Station 03
- `Luis.mp3` für Station 04
- `BenAudio.mp3` für Station 05
- `ErikAudio.mp3` für Station 06
- `Song.mp3` für Station 07


Öffne die HTML-Datei zum Testen möglichst über einen Webserver oder veröffentliche
den Ordner direkt auf Netlify. Beim direkten Öffnen über `file://` blockieren
manche Browser lokale Audio-Dateien aus Sicherheitsgründen.

Die Titel der Kreise kannst du direkt in [index.html](./index.html) ändern. Weitere Kreise lassen sich dort nach dem Muster eines bestehenden `article`-Elements ergänzen.

Die Bilder und Videos liegen im Ordner `media`, die Audios im Ordner `audio`.

Die sieben Karten sind in drei Audio-Reihen angeordnet. Pro Reihe kann immer
nur eine Nachricht gleichzeitig laufen; in einer anderen Reihe kann parallel
eine weitere Nachricht abgespielt werden.

## Auf Netlify veröffentlichen

1. Öffne [netlify.com](https://www.netlify.com/) und melde dich an.
2. Ziehe den gesamten Projektordner in den Bereich für manuelle Deploys.
3. Die Website ist direkt unter der von Netlify vergebenen URL erreichbar.
